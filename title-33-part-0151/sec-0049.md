# § 151.49 Category C and D Oil-like NLSs allowed for carriage.
The following is a list of Category C and D Oil-like NLSs that the Coast Guard allows to be carried:
(a) The following Category C oil-like NLSs may be carried:
Aviation alkylates Cycloheptane Cyclohexane Cyclopentane p-Cymene Ethylcyclohexane Heptane (all isomers) Heptene (all isomers) Hexane (all isomers) Hexene (all isomers) iso-Propylcyclohexane Methyl cyclohexane 2-Methyl-1-pentene, see Hexene (all isomers) Nonane (all isomers) Octane (all isomers) Olefin mixtures (C5-C7) Pentane (all isomers) Pentene (all isomers) 1-Phenyl-1-xylylethane Propylene dimer Tetrahydronaphthalene Toluene Xylenes
(b) [Reserved]
