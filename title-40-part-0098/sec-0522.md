# § 98.522 GHGs to report.
You must report:
(a) CO 2 process emissions from each ceramics process unit (e.g., kiln, dryer, or oven).
(b) CO 2 combustion emissions from each ceramics process unit.
(c) CH 4 and N 2 O combustion emissions from each ceramics process unit. You must calculate and report these emissions under subpart C of this part by following the requirements of subpart C of this part.
(d) CO 2, CH 4, and N 2 O combustion emissions from each stationary fuel combustion unit other than kilns, dryers, or ovens. You must report these emissions under subpart C of this part by following the requirements of subpart C of this part.
