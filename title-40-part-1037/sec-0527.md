# § 1037.527 Aerodynamic measurements for vocational vehicles.
This section describes a methodology for determining aerodynamic drag area, C d A, for use in determining input values for vocational vehicles as described in § 1037.520. This measurement is optional.
(a) Determine ΔC d A values by performing A to B testing as described for trailers in § 1037.526, with any appropriate adjustments, consistent with good engineering judgment.
